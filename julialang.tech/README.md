# 炬力郎
> 为开发者在开发阶段提供一站式服务
## 项目介绍
- 焰力郎是一个为开发者提供一站式服务的平台，包括代码托管、持续集成、持续部署、项目管理、文档管理、团队协作等功能。
- 焰力郎采用前后端分离的架构，前端使用Vue.js框架，后端使用Node.js框架，数据库使用MySQL。
- 焰力郎提供私有化部署方案，用户可以根据自己的需求进行定制化开发。

## 功能介绍
- 代码托管：提供代码仓库管理、代码审查、代码合并等功能。
- 持续集成：提供自动化构建、测试、部署等功能。
